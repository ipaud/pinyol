Mesurat a la consola, no promès

Cada xifra d'aquesta secció surt de la placa: un firmware que juga sol seguint un guió i escriu una línia de rendiment per segon, o un banc de proves que repeteix cada escena cinc vegades. Sense emulador. A 60 fps, cada fotograma dura 16,6 ms.

  • 71%d'un nucli a l'escena més pesada: capa afí, quatre capes i 128 sprites
  • 8,1msper enviar un fotograma sencer al panell; només el cable ja en són 7,7
  • 3%d'un nucli per al so mentre es juga
  • 112proves que juguen soles i comparen cada fotograma, a cada canvi

Font: docs/measurements.md (s'obre en una pestanya nova), amb el mètode i cada mesura des del primer dia. Mesura-ho a la teva placa: idf.py -DBP_BENCH=ON build flash monitor

Fes-te un joc

pinyol està pensat per fer-lo servir amb un agent de codi, com Codex o Claude Code. L'agent llegeix les instruccions del repositori, instal·la el que falta, segueix la recepta de l'aspecte que demanis i prova el joc abans de donar-te'l.

  1. Baixa el motor

    En un Mac amb Homebrew o a Linux.

    git clone https://github.com/ipaud/pinyol.git
cd pinyol

  2. Demana-ho al teu agent

    Obre la carpeta amb el teu agent i digues-li què vols, en el teu idioma.

    Fes-me un joc de plataformes amb aspecte de Game Boy: un ratolí que busca formatge en una biblioteca.

  3. Juga-hi

    A l'ordinador, o passa'l a la consola per USB.

    ./build/pinyol_sim --game games/raton
Sense programar? L'editor web fa el mateix amb dibuixos i blocs, al navegador.

Sense programar · al navegador

L'editor

Dibuixa els personatges píxel a píxel, pinta els mapes, defineix les regles amb blocs i juga-hi a l'instant. Comença de zero o a partir d'una plantilla, com Abella o LÍNEA 0.

  • Aspecte de consola Game Boy, Game Boy Advance, PICO-8, ZX Spectrum o 16 bits: els seus colors i la seva tipografia
  • Dibuixos que es mouen píxel a píxel, amb animacions per estar quiet, caminar o rebre un cop
  • Regles amb blocs vides, compte enrere, diàlegs, rècords que es desen
  • So efectes a partir de receptes, música composta en una quadrícula o un .mod
  • A la consola pel cable USB o en un .zip per a la targeta
  • En tres idiomes castellano, català i English

La consola

Una placa de desenvolupament amb pantalla, que es compra ja muntada. El motor l'esprem: dibuixa directament en franges, reparteix la feina entre els dos nuclis i guarda a la targeta el que no cap a la memòria.

Placa
Freenove FNK0104N
Chip
ESP32-S3R8, dos nuclis a 240 MHz
Memòria
512 KB de RAM interna, 8 MB de PSRAM, 16 MB de flash
Pantalla
3,5″, 480×320, ST77922 per QSPI, tàctil
So
ES8311 amb altaveu
La resta
microSD, bateria, USB

Instal·la el firmware des del navegador

  1. Connecta la placa a l'ordinador per USB.
  2. Prem el botó i tria el port de la placa.
  3. Espera uns minuts: arrenca amb 15 jocs a la memòria.
Aquest navegador no pot parlar amb la placa per USB: obre aquesta pàgina a Chrome o Edge, en un ordinador. Per instal·lar, cal obrir la pàgina amb https.

A RetroArch i RetroPie

Sense la consola? El motor també és un nucli de libretro: els jocs de pinyol es juguen a RetroArch i a tot el que s'hi basa, com RetroPie o Lakka en una Raspberry Pi, Batocera, Recalbox, les portàtils que el porten o un ordinador. És el mateix motor, així que el joc és el mateix.

  1. Instal·la'l a RetroPie

    A la Raspberry Pi, aquesta ordre descarrega el nucli ja compilat (una Pi 1 o Zero el compila, en uns minuts) i afegeix Pinyol a EmulationStation.

    cd ~/RetroPie-Setup
curl -fsSL --create-dirs \
  -o ext/pinyol/scriptmodules/libretrocores/lr-pinyol.sh \
  https://raw.githubusercontent.com/ipaud/pinyol/main/platform/libretro/lr-pinyol.sh
sudo ./retropie_packages.sh lr-pinyol

  2. Copia els jocs

    El .zip de qualsevol joc, com els que es descarreguen aquí, va a la seva carpeta.

    ~/RetroPie/roms/pinyol/

  3. Juga

    Reinicia EmulationStation i apareix Pinyol amb els seus jocs. Al comandament, X o Y fan de C, i SELECT de MENU.

Com es va fer

  • 15.386línies de C al motor
  • 33jocs d'exemple
  • 112proves a cada canvi
  • 190commits al repositori

Una persona i Claude. El motor, els exemples, les eines i aquest web es van escriure parlant amb Claude Code: cada idea es provava al simulador, es mesurava a la placa i es corregia segons el que deia la placa.

L'art, generat i encaixat. Els aspectes que ho demanen (Neo Geo, CPS2, 32 bits) fan servir imatges generades amb IA. Les eines del motor les retallen, les escalen a l'alçada justa, en separen els fotogrames i les redueixen a la paleta de la consola. Els aspectes de baixa resolució es dibuixen amb codi.

Mesurat abans de donar-ho per bo. Cada exemple té un guió que hi juga sol. A l'ordinador, compara la suma de control de cada fotograma amb la desada; a la placa, escriu els fps de cada segon. Les optimitzacions no canvien ni un píxel.

Lliure de debò. El codi és MIT; l'art, el so i els vídeos dels exemples, CC0. Agafa-ho, canvia-ho, fes la teva consola.
