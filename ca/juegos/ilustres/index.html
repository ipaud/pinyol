Marques, privacitat i dades

Game Boy, PICO-8, Neo Geo i les altres consoles esmentades són marques dels seus propietaris; pinyol i Cirera no hi tenen cap relació.

Apple, Mac i macOS són marques d'Apple; Windows, de Microsoft, i Linux, de Linus Torvalds.

Les visites, les partides i el temps jugat es compten amb GoatCounter (s'obre en una pestanya nova), sense galetes ni dades personals.

Els comentaris i els vots de cada joc es desen a GitHub i es carreguen amb giscus només si els demanes.

La Biblioteca, el rànquing i les xifres de cada joc es llegeixen de GitHub en obrir la pàgina.
