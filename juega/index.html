Marcas, privacidad y datos

Game Boy, PICO-8, Neo Geo y las demás consolas que se nombran son marcas de sus dueños; pinyol y Cirera no tienen relación con ellos.

Apple, Mac y macOS son marcas de Apple; Windows, de Microsoft, y Linux, de Linus Torvalds.

Las visitas, las partidas y el tiempo jugado se cuentan con GoatCounter (se abre en una pestaña nueva), sin cookies ni datos personales.

Los comentarios y los votos de cada juego se guardan en GitHub y se cargan con giscus solo si los pides.

La Biblioteca, el ranking y las cifras de cada juego se leen de GitHub al abrir la página.
